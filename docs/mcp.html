InDays MCP

Log office days, plan ahead, and track attendance targets from your AI app.

Server URL: https://indays.saad.sh/mcp

ChatGPT

  1. Open ChatGPT Plugins on the web. Select + → Add custom MCP server.
  2. Set Name to In Days. Description and icon are optional. For the icon, use this PNG, which is under 10 KB.
  3. Under Connection, choose Server URL and enter https://indays.saad.sh/mcp.
  4. Choose OAuth for Authentication.
  5. Review and check I understand and want to continue, then select Create as a plugin.
  6. Install the plugin and connect it by signing in with Google or GitHub when prompted.

No public directory listing is needed for personal use. Account and workspace permissions apply. See the official OpenAI setup guide.

ChatGPT on iOS

After setup on the web, open ChatGPT on your iPhone with the same account and workspace. Start a new chat and select In Days using @. Try: “Log today as an office day.” OpenAI's plugin guide covers mobile availability.

Claude

Add InDays to Claude, then sign in with Google or GitHub. You can also add a custom connector in Customize → Connectors using the server URL above.

Other MCP clients

Add the server URL as a remote Streamable HTTP server with OAuth.

What you can do

  • Log office, planned, and excused days, with optional locations and notes.
  • Check progress toward company windows or your own targets.
  • Plan how many office days you need each week.
  • Compare office days by weekday, month, or location.
  • Import the InDays app's Export Data file.
  • Clear days, delete filters, or delete your MCP account.

App data and MCP data

The MCP service stores its own data. Signing in with the same provider as the native app does not sync the two. To bring app records into MCP, export your data from the app and ask your AI app to import the file.
